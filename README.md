# 5-Month AI/AGI Engineer Roadmap (GitHub Pages)

This repository contains a complete static website you can publish with **GitHub Pages**.

## Publish
1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Set source to **Deploy from branch** and choose `main` (or current branch root).
4. Save and wait for the URL.

## Local preview
```bash
python3 -m http.server 8000
```
Open <http://localhost:8000>.
