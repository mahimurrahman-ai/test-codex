Detailed 5-Month Roadmap

Month 1 — Web foundations + GitHub workflow

Outcome: You can build and deploy clean, responsive websites with GitHub collaboration.

Learn

  • Semantic HTML, forms, accessibility basics
  • CSS layout (Flexbox/Grid), responsive design
  • JavaScript fundamentals (DOM/events/fetch)
  • Git, branching, pull requests, issues
  • GitHub Pages deployment

Do not learn yet

  • React/Vue before vanilla JavaScript confidence
  • Complex animation libraries

Build this month: Personal learning site + task tracker app.

Month 2 — JavaScript depth + API integration

Outcome: You can integrate external APIs and ship real data-driven UI.

Learn

  • Async/await and robust error handling
  • REST APIs, JSON, pagination, rate limits
  • Frontend state management patterns
  • Testing basics for core JS functions

Do not learn yet

  • Micro-frontend architecture
  • Over-engineered build pipelines

Build this month: API-powered AI news and trend dashboard.

Month 3 — Python for AI engineering

Outcome: You can write production-grade Python scripts and LLM-powered tools.

Learn

  • Python core, typing, modules, testing
  • venv/poetry, dependency and environment management
  • Data handling with pandas + numpy fundamentals
  • LLM API SDK usage, prompt workflows, retries

Do not learn yet

  • Training transformer models from scratch
  • Heavy MLOps stacks too early

Build this month: Python CLI that summarizes repositories/docs using an LLM API.

Month 4 — Backend API engineering

Outcome: You can build secure backend APIs serving both app and AI features.

Learn

  • FastAPI routes, pydantic models, validation
  • Database CRUD (SQLite/Postgres) and migrations
  • JWT auth, request limits, background tasks
  • Logging + monitoring basics

Do not learn yet

  • Premature microservices split
  • Kubernetes before shipping core product value

Build this month: FastAPI service with CRUD + one AI endpoint.

Month 5 — Agent systems + deployment

Outcome: You can ship an end-to-end AI product with retrieval, evaluation, and CI/CD.

Learn

  • Agent patterns: tool-use, planning, memory trade-offs
  • RAG: chunking, embeddings, retrieval quality
  • Evaluation: latency, quality, cost trade-off
  • Docker, deployment, GitHub Actions CI/CD

Do not learn yet

  • Custom frontier model training
  • GPU cluster optimization before product traction

Build this month: Deployed AI assistant with docs upload and retrieval.

Portfolio projects to prove you can build

  1. Roadmap landing page on GitHub Pages
  2. API dashboard web app
  3. Python LLM command-line assistant
  4. FastAPI backend with auth + AI endpoint
  5. Public AI assistant with CI/CD and monitoring

Weekly schedule template

  • Mon–Thu: 2–3h deep work (new concepts + coding)
  • Friday: Refactor, tests, clean commits
  • Saturday: Add a feature + deploy demo
  • Sunday: Publish short build log and plan next week
