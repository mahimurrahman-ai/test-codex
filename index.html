5-Month AI/AGI Engineer Learning Path

A focused, job-oriented plan for web + Python + APIs + AI systems, with clear goals and projects each month.

View Roadmap Build Projects

How this plan is designed

  • Fast execution: learn only what you can apply immediately.
  • Portfolio-first: every month ends with a working project.
  • AI engineering focus: APIs, Python tooling, model usage, and deployment.

Monthly Roadmap (Total: 5 Months)

Month 1 — Web Foundations + GitHub Workflow

Goal: Build and publish real static and interactive web pages.

Learn

  • HTML5, semantic structure, forms
  • Modern CSS (Flexbox/Grid, responsive design)
  • JavaScript basics (DOM, events, fetch)
  • Git + GitHub (branch, commit, PR, Issues)
  • Deploying with GitHub Pages

Do not learn yet

  • Complex frontend frameworks (React/Vue) before JS fundamentals
  • Heavy animations and design systems

Build: Personal roadmap website + a mini task tracker app.

Month 2 — Deeper JavaScript + API Integration

Goal: Consume real APIs and manage client-side data flows.

Learn

  • Async JavaScript (async/await, error handling)
  • REST API basics and JSON contracts
  • Auth basics (API keys, OAuth conceptually)
  • State handling in vanilla JS
  • Testing basics with simple unit tests

Do not learn yet

  • Micro-frontend architecture
  • Exotic JS build tooling

Build: AI-news dashboard fetching from multiple APIs.

Month 3 — Python for AI Engineering

Goal: Use Python confidently for automation and data processing.

Learn

  • Python core (functions, classes, typing)
  • Virtual environments + dependency management
  • Data tools: pandas, numpy basics
  • CLI scripting and file processing
  • Prompting workflows and SDK usage for LLM APIs

Do not learn yet

  • Research-level deep learning math derivations
  • Distributed training infra

Build: Python command-line tool that summarizes docs with an LLM API.

Month 4 — API Engineering + Backend

Goal: Build production-style AI-enabled backend services.

Learn

  • FastAPI fundamentals (routes, models, validation)
  • Database basics (PostgreSQL/SQLite, CRUD)
  • Background jobs, caching, rate limits
  • Auth/JWT basics
  • Observability (logging, metrics, tracing basics)

Do not learn yet

  • Premature microservices split
  • Overly complex cloud architecture

Build: FastAPI service with one AI endpoint and one standard CRUD endpoint.

Month 5 — AI Agent Systems + Deployment

Goal: Deliver an end-to-end AI product publicly.

Learn

  • Agent patterns (tool use, planning, memory trade-offs)
  • RAG fundamentals (chunking, embeddings, retrieval)
  • Evaluation basics (quality, latency, cost)
  • Containerization and deployment (Docker + simple cloud host)
  • CI/CD with GitHub Actions

Do not learn yet

  • Trying to train your own frontier model
  • Over-optimizing GPUs before product-market validation

Build: AI assistant web app with retrieval + deployment + monitoring.

Portfolio Projects You Should Finish

  1. GitHub Pages Roadmap site (Month 1)
  2. API-powered dashboard (Month 2)
  3. Python LLM CLI assistant (Month 3)
  4. FastAPI AI microservice (Month 4)
  5. Deployed AI product with CI/CD (Month 5)

Tip: Keep each project small, complete, documented, and publicly demoable.

Weekly cadence (works for all months)

  • Mon–Thu: 2–3 hours learning + coding
  • Fri: Refactor + write README
  • Sat: Add one feature + tests
  • Sun: Publish progress update on GitHub/LinkedIn
